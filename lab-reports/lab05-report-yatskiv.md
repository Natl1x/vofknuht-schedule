# Звіт до лабораторної роботи №5

**Тема:** REST API для проєкту «Інтерактивний розклад ВоФК НУХТ».

| Відомості | Значення |
| --- | --- |
| Виконавець | Максим Яцків, ІПЗ 21 |
| Склад команди | Максим Яцків |
| Предметна область | Формування та перегляд навчального розкладу |
| Технології | Python, Flask, SQLite, OpenAPI 3.0, Postman/Newman |

API працює з тією самою SQLite-базою, що й сайт. Публічні запити повертають
групи, дисципліни та опубліковані пари; адміністративні змінюють розклад;
викладачі керують коментарями лише до власних занять. Відповіді й помилки
мають формат JSON, а успішне видалення повертає `204` без тіла.

## Маршрути й документація

Повна таблиця 13 операцій із методами, правами та кодами відповіді міститься
в [README](../README.md#rest-api--лабораторна-робота-5). Схеми вхідних і
вихідних даних та приклади наведено в [OpenAPI](../docs/openapi.json) і на
сторінці `/apidocs/`.

Версії `/api/v1` і `/api/v2` використовують ті самі ресурси. У v1 заняття
містить базові поля; v2 додатково повертає дату поточного тижня, тип пари,
підгрупу, коментар і стан публікації. Вхід через `POST /session` встановлює
cookie Flask; ролі обмежують адміністративні запити. Валідація відхиляє
неправильні типи й невідомі поля (`400`), неіснуючі ресурси (`404`),
несанкціоновані дії (`401`/`403`) та конфлікт зайнятості (`409`).

## Тестування

Колекція [Postman](../docs/postman_collection.json) містить 32 послідовні
сценарії: успішний і помилковий запит для кожної групи маршрутів. Вона
перевірена Newman на свіжій тимчасовій базі: **32 запити, 61 перевірка,
0 помилок**. Автоматичний набір `python -m unittest discover -s tests -v`
перевіряє версії, ролі, валідацію, CRUD пар, коментарі та попередній
функціонал сайту.

Скріншоти: [документація](screenshots/lab05-api-docs.png),
[успішна JSON-відповідь](screenshots/lab05-api-success.png),

відкриті в браузері; колекцію виконано окремо через Newman.

## Труднощі та висновки

Потрібно було зберегти поведінку HTML-сторінок і водночас віддавати помилки
API як JSON. Обробники розрізняють маршрути `/api/` та звичайні сторінки.
Обмеження `UNIQUE` у SQLite використовуються для виявлення конфліктів пар,
які API повідомляє кодом `409`. Застосунок має задокументований API з двома
версіями й перевіреними сценаріями для роботи з розкладом.
