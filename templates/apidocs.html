API розкладу

JSON API використовує базу даних цього сайту. Повний опис схем запитів і відповідей: OpenAPI 3.0.

Версії та доступ

Замініть {version} на v1 або v2. У v2 заняття додатково містить дату поточного навчального тижня, тип заняття, підгрупу, коментар і стан публікації. Для захищених запитів виконайте POST /api/v1/session; клієнт зберігає отриманий cookie сеансу.

Маршрути

Усі відповіді та помилки API мають формат JSON, крім успішного видалення (204).

Метод Адреса після /api/{version} Призначення та доступ Коди
POST /session Вхід за email і password 200, 400, 401, 415
DELETE /session Вихід 204
GET /groups Список груп 200
GET /subjects Список предметів 200
GET /groups/{id}/lessons Опубліковані пари групи 200, 404
GET /lessons/{id} Одна пара 200, 404
POST /feedback Створити відгук 201, 400, 415
GET /feedback Відгуки; email доступний лише адміністратору 200
POST /lessons Створити пару · адміністратор 201, 400, 401, 403, 409
PATCH /lessons/{id} Змінити пару · адміністратор 200, 400, 401, 403, 404, 409
DELETE /lessons/{id} Видалити пару · адміністратор 204, 401, 403, 404
PUT /lessons/{id}/comment Зберегти коментар · викладач цієї пари 200, 201, 400, 401, 403, 404
DELETE /lessons/{id}/comment Видалити коментар · викладач цієї пари 204, 401, 403, 404
