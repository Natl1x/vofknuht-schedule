# Інтерактивний розклад ВоФК НУХТ

Вебзастосунок для перегляду розкладу занять. Поточна версія містить демонстраційні дані.

Єдиний учасник проєкту — Максим Яцків.

## Запуск у Windows

Потрібен Python 3.12 або новіший. У поточній робочій папці вже налаштовано Python 3.13 та встановлено залежності.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Відкрити http://127.0.0.1:5000. У PyCharm можна запустити main.py.
Якщо порт зайнятий: `.venv\Scripts\python.exe -m flask --app main run --port 5001`.
Зупинка сервера — Ctrl+C.

## Перевірка критеріїв

| Вимога | Реалізація |
|---|---|
| Flask, головна, про нас | main.py, home.html, about.html |
| Не менше двох додаткових статичних сторінок | /schedule та /help |
| Меню на всіх сторінках | base.html, url_for, позначення активної сторінки |
| Адаптивність | viewport, CSS Grid, media queries 900 і 620 px |
| Чистий структурований код | окремі маршрути, шаблони, CSS; коментарі й docstring |
| Творчий підхід | власне оформлення розкладу, картки днів, довідка |
| Середовище та залежності | .venv, requirements.txt, .gitignore |
| Звіт зі скріншотами | lab-reports/ |

Реєстрація, база даних, адмінпанель та редагування заплановані для наступних версій.
Назва описує майбутній інтерактивний сервіс; поточна версія статична.
Довідка використовує стандартні HTML details/summary без JavaScript.

## Структура та перевірки

- main.py — запуск, маршрути, демонстраційні дані.
- templates/base.html — спільний каркас; інші шаблони успадковують його.
- static/css/style.css — локальне оформлення без CDN.
- tests/test_app.py — HTTP-статуси, меню, внутрішні посилання, розклад, CSS і 404.

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```
