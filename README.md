# Інтерактивний розклад ВоФК НУХТ

Flask-застосунок для перегляду та формування навчального розкладу. Дані
зберігаються у SQLite; адміністратор формує пари й створює облікові записи
викладачів, а викладачі залишають коментарі лише до закріплених за ними пар.

## Запуск

Потрібен Python 3.13+.

```bash
uv sync
uv run python main.py
```

На цьому комп’ютері відкрийте `http://127.0.0.1:5000`. Для доступу з іншого
пристрою тієї самої локальної мережі відкрийте `http://IP-АДРЕСА_КОМП’ЮТЕРА:5000`
(наприклад, `http://192.168.1.25:5000`). Якщо сторінка не відкривається,
дозвольте порт 5000 у брандмауері. Під час першого запуску автоматично
створюється `instance/schedule.db` та наповнюється демонстраційними даними.

## Демонстраційні акаунти

| Роль | Email | Пароль |
| --- | --- | --- |
| Адміністратор | `admin@vofknuht.local` | `admin123` |
| Викладач | `melnyk@vofknuht.local` | `teacher123` |

У реальному застосунку секретний ключ та початкові паролі слід змінити через
змінні середовища. Вони вказані тут лише для демонстрації лабораторної роботи.

## Можливості

- стартова сторінка з вибором групи та автоматичним завантаженням її розкладу;
- світла й темна тема, вибір якої зберігається у браузері;
- експорт розкладу групи до файлу `.ics` для Google Calendar, Apple Calendar та Outlook;
- форма відгуків;
- вхід за ролями `admin` і `teacher`;
- адмінпанель для викладачів, груп, предметів, аудиторій, відгуків і пар;
- одна дисципліна в довіднику, окремий вибір типу заняття та підгрупи для кожної пари;
- контроль конфліктів групи, викладача й аудиторії в один час;
- кабінет викладача з коментарями до власних занять.
- завантаження фото розкладу в адмінпанелі для подальшого розпізнавання.

Для розпізнавання українського тексту з фото на сервері потрібні Tesseract та
українська мовна модель `ukr.traineddata` у `instance/tessdata/`.

У формі заняття окремо обираються навчальна група, дисципліна, тип заняття
(лекція, практичне, лабораторна або «Не вказано») та підгрупа («Уся група»
або номер). Під час оновлення старі позначення на кшталт «Програмування (ЛР 2)»
переносяться в поля заняття, а дублікати дисциплін об'єднуються зі збереженням
пар і коментарів.

## Перевірка

```bash
uv run python -m unittest discover -s tests -v
```

Тести перевіряють публічні сторінки, створення й перегляд відгуків, обмеження ролей, коментарі
викладача й заборону конфліктів у розкладі.
