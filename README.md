# Інтерактивний розклад ВоФК НУХТ

Вебзастосунок Flask для перегляду демонстраційного тижневого розкладу. Тема — Волинський фаховий коледж Національного університету харчових технологій. Єдиний учасник проєкту — Максим Яцків.

## Запуск у Windows

Потрібен Python 3.12 або новіший. Створіть середовище, встановіть залежності та запустіть сервер:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Відкрийте http://127.0.0.1:5000. Зупинка сервера — Ctrl+C. Альтернативно можна встановити залежності через uv із `pyproject.toml` і `uv.lock`.

## Відповідність завданню

| Вимога | Реалізація |
|---|---|
| Flask-застосунок, головна та «Про нас» | `main.py`; `templates/home.html`, `templates/about.html` |
| Щонайменше дві додаткові статичні сторінки | `/schedule`, `/help` |
| Усі сторінки доступні через спільне меню | `templates/base.html`; адреси формує `url_for` |
| Адаптивна верстка | `static/css/style.css`: CSS Grid і медіазапити 900 та 620 px |
| Контент відповідає предметній області | Демонстраційний розклад, інформація про сервіс і довідка |
| Правильний час занять | Початок 08:00, пари по 80 хв, перерви 10 хв і 30 хв після другої пари |
| Чистий структурований код | Окремі маршрути, спільний шаблон, окремий CSS, коментарі та docstring |
| Python-залежності | `requirements.txt`, `.venv/` і `.gitignore` |
| Звіт і скриншоти сторінок | `lab-reports/lab03-report-yatskiv.md` та `lab-reports/screenshots/` |

Заняття і час у розкладі є демонстраційними, а не офіційними даними коледжу. Реєстрація, база даних, особисті розклади й адмінпанель залишені для наступних версій.

## Перевірка

Запустіть автоматичні перевірки:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Перевірки охоплюють доступність усіх чотирьох сторінок, меню та внутрішніх посилань, повноту демонстраційного розкладу, завантаження CSS і обробку помилки 404.

Звіт містить персональні дані, внесок, посилання на коміт, скриншоти у звичайному та мобільному вигляді, труднощі з рішеннями й висновки. Вимогу групового формату (3–4 особи) та захист роботи слід узгодити й виконати відповідно до правил курсу.
